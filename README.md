# 每日韩语 v0.5.6

基于已选定的「今日一句」方向制作的完整学习版本。原 v0.4.3 与原始教材未修改。

## 已完成

- 252 课：首尔大学韩国语 1A–6B、维他命韩国语 1–6。
- 真实课程对话、词汇、语法、发音、替换练习、练习本、文化与 AI 场景。
- 30 / 90 / 180 / 365 天日卡，含新课、开口、复习与轻量日。
- 分级提示、表达后重试、FSRS 复习、漏做恢复卡。
- 桌面宽屏与手机布局；Mac 独立 App ID `com.family.korean.daily`。
- 现有 Edge TTS 缓存音频；网页新增表达经本机中转生成韩语朗读。

## 预览

`PORT=5199 node tools/serve.mjs`

## Mac 构建

```bash
npm install
npm run fonts
npm run mac:share
```

输出在 `releases/mac/0.5.6/`。当前完整安装包留在工作目录的同一目录，未随仓库上传。

与旧版独立安装、独立存档；不覆盖原 App 或其学习记录。沿用原项目的临时签名，无 Apple 公证。
